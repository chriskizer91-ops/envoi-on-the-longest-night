merged into one game (Coven of the Moon Faire) in a new repository. This folder is a record. No game file was changed.

## How the copies were made, and the one change

The 13 documents were typed out from the project's text, because the project hands its documents over as text and not
as files. As a check, the two longest slips were compared line by line with the copies their own jobs keep in this
repository: `slips/world-map.md` against branch `work/world-map`, and `slips/world-3d.md` against `work/world-3d` and
`work/reskin`. Both matched with 0 lines different. The other 11 have no second copy to compare with.

**One change, on purpose.** This repository is public. `claude/lore/io-and-kore.md` and the Io and Kore lore page each
held the same two sentences about Chris's family. They are left out of both copies here, and the spot is marked. The
project document and the artifact still have them. The other 12 documents are as they are in the project.
