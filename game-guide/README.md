# Game guide

*MOTHLIGHT Player's Guide: Envoi on the Longest Night*, a walkthrough laid out like a late-'90s game magazine.

- Open `index.html` in a browser, or read the published page: https://claude.ai/artifact/Sgb5AQLuuwsmjdrnBxe7zN
- It covers the October 2026 build of the game (`Envoi-on-the-Longest-Night-1.html`). The numbers, maps, keepsakes and dialogue all come from that file.
- `images/` holds the area maps, the world map, the keepsake pictures, the character art and the screenshots taken in the game.
- The keepsake checklist saves its ticks in the reader's own browser.

Nothing outside this folder was changed to make it.
