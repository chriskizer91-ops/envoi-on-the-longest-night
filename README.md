# Envoi on the Longest Night

*(working title)*

A game in early development.

## Status

Phase 1, the model touch-ups (see `docs/plan.md`). Noctara is done.

## Layout

- `docs/`: lore, specs, the project brief, and `landscape.md` (an inventory of what exists).
- `reference/demos/`: the single-file HTML demos this game starts from.
- `reference/art/`: concept art and pose sheets.
- `reference/renders/`: renders of the 3D models, kept as before-and-after records.
- `src/models/`: the code-built 3D models, one file each; `originals/` keeps the untouched versions.
- `src/bench/`, `demos/`, `dist/`: the shared battle bench, each model's bench page, and the built single-file pages.
- `tools/`: build, headless checks, turnaround renders and the line-up. See `docs/model-touchup-guide.md`.
