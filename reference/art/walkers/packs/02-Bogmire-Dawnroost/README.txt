AETHERMOOR: PAPER-DOLL WALK SHEETS

19 selected character sheets; 456 illustrated frames in total.
Each original PNG is 1536 x 1024, RGBA, with real transparency.
Six columns; four directional rows: front, left, right, back.
The nominal cell size is 256 x 256. Extract all three ZIPs into the
same project root; artwork lands in reference/art/walkers/.

Io's supplied sheet was the style/layout reference. The additional Sol,
Halcyon and Ysmera portraits/model sheets named in the brief were not
supplied; their appearance was generated from the written descriptions.
Two candidates were generated for each character, with a third size
correction for Pell, Tamsin, Pim and Tock. One final sheet is included
per character. Images were generated using the built-in image tool.

INTEGRATION
These are full-size illustrated source sheets, ready for the frame
extraction and phone compression step described in the supplied brief.
Use the alpha channel, not the RGB values in transparent pixels.
Transparent pixels can retain colored RGB data and may look colored
in a previewer that ignores alpha.

Small pose and spacing variations remain. Find figures using alpha-aware
bounds rather than assuming every visible pixel lies within a rigid
256 x 256 crop. Normalize foot anchors after extraction and verify walk
playback in the game. Keep a consistent scale across frames for each
person. The measured sizes are approximate: the manifest gives the
intended world-height ratios (adults 1.0, girls 0.75, gnomes 0.667,
Ysmera slightly taller). Use those ratios when setting map render sizes.

The final PNGs retain original generator bytes; they have not been
quantized, resized, or converted to green-screen assets. Frame cutting,
runtime compression and game integration are still to be performed by
the coding agent, as requested in Art Request 08.
